# Appliance State Reconstruction

Home Assistant automation showcase for reconstructing robust appliance states from incomplete, delayed or inconsistent data sources.

## Kurzbeschreibung

Entwicklung eines Frameworks zur Rekonstruktion robuster Gerätezustände aus mehreren unvollständigen, zeitversetzten oder fehleranfälligen Datenquellen. Die zugrundeliegenden Konzepte werden unter anderem für die Überwachung und Steuerung eines Geschirrspülers eingesetzt.

## Schwerpunkte

- Zustandsrekonstruktion
- Ereignisgesteuerte Systeme
- Zustandsautomaten
- Recovery-Mechanismen
- Synchronisation verteilter Datenquellen
- Fehlertolerante Automatisierung
- Benutzerfreundliche Statusdarstellung

## Technologien

- Home Assistant
- YAML
- Event Processing
- State Machines
- JSON
- Git
- Automation

## Enthaltene Automation

- `005_auto_geschirrspueler.yaml` – Rekonstruktion eines stabilen Gerätezustands

## Hinweis

Die YAML-Datei ist eine Showcase- und Referenzdatei. Entity-Namen müssen an die jeweilige Home-Assistant-Installation angepasst werden.
